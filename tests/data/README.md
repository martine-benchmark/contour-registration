# Test fixtures

Three objects of the [Martine dataset](https://doi.org/10.7910/DVN/2BEPEH) (`lego`, `spine`,
`surgery_scissors`), downscaled to 512×341: a few images, one mask per view, a mesh and the
same cameras in the three supported pose formats (`meshroom/`, `colmap/`, `idr/`).

Derived from the Martine dataset, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Cite the Martine paper (see the [README](../../README.md#citation)) when reusing them.
